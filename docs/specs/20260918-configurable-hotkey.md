# 设置唤醒快捷键

设置页提供录入、Esc 取消和恢复默认，保存后生效。支持 Alt/Ctrl 加空格、字母、数字或 F1–F11，可加 Shift；不支持单键及系统 Windows 键组合。旧数据和无效数据回退 Alt+空格。

修改采用先注册新组合、再保存数据、最后释放旧组合的顺序。被占用时不保存；保存失败时释放新注册并保留旧键。默认组合仍使用现有优先捕获逻辑，自定义组合使用 Windows 全局注册。录入时暂停默认钩子，当前已注册组合由消息通道传给录入器，避免隐藏窗口；失焦、离页及取消时恢复监听。

托盘、状态提示与保存数据统一读取当前设置。测试覆盖格式、兼容回退、加密持久化、冲突、保存失败回滚、旧键释放、录入取消及默认恢复。未修改或安装用户正式版本。
