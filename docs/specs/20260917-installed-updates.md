# 安装版检查更新

用户要求增加检查版本更新，明确便携版不提供、安装版提供。随后明确要求单文件 Setup.exe 分步安装向导，不创建快捷方式，只保留安装完成后后台运行。本次沿用当前工作区，保留之前的替换和界面修复。

## 范围

- 编译时区分 Portable（默认）和 Installed，安装版设置页显示版本和“检查更新”；便携版隐藏此区域且不发送检查请求。
- 用户主动点击后读取 langji3/cliptap 的 GitHub latest Release，排除草稿/预发布，比较版本，显示最新、可更新、暂无发布或查询失败。新版本须包含安装版压缩包；提供打开该 Release 的按钮，由用户下载安装。不做静默下载、自替换或自动执行安装。
- 使用 Inno Setup 提供中文 Setup.exe 向导：欢迎、选择安装位置、确认安装、进度、完成。默认 `%LOCALAPPDATA%\Programs\ClipTap`，可选择位置；不创建桌面或开始菜单快捷方式。完成页默认勾选后台运行，使用 `--background` 驻留托盘，不弹主窗口。当前用户卸载登记；卸载保留 `%LOCALAPPDATA%\ClipTap` 数据。安装包自带 .NET 运行时，无需管理员权限。
- 构建脚本与 CI 产出 `ClipTap-win-x64-setup.exe`；更新查询同步识别该附件，现有便携包保留。README 说明安装与升级流程，以及当前尚无正式 Release。移除先前 PowerShell 用户安装流程。
- 不在本任务中自动公开发布 Release 或提交/推送未审阅的现有修改。

## 验证

构建与现有测试；使用假的 HTTP 响应覆盖新旧版本、无 Release、网络错误、非法链接、草稿/预发布、缺失安装资产和便携版零请求；检查设置页和向导界面。使用独立测试 AppId 在隔离目录实际执行 EXE 安装、覆盖升级和卸载，检查运行时、卸载登记和用户文件保留。替换偶发失效另行保留为待复现问题，不以此次更新功能宣称解决。
