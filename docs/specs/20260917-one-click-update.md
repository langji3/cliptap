# 安装版一键更新

用户授权：新增点击更新后自动下载、校验、静默覆盖当前目录并重启到托盘，完成后发布。不得在用户机器上实际安装测试。

使用 GitHub latest 正式发布元数据及其安装包 SHA-256；下载 URL 固定为项目仓库，缺少校验值时仅支持手动下载。最大 256 MiB，下载超时 15 分钟。下载大小及完整哈希必须匹配；失败保留当前进程。

通过隐藏 PowerShell 辅助进程等待当前 PID 退出。辅助进程先反馈 ready；主程序保存成功才写入 commit 并退出。超时、取消、保存失败不授权安装。辅助进程再次验证哈希，使用 Inno Setup 的 /VERYSILENT /SUPPRESSMSGBOXES /SP- /NORESTART，/DIR 显式为当前程序目录。安装成功才启动 --background；失败提示并保留日志。数据文件不进入安装包。

兼容限制：0.1.0 / 0.1.1 必须手动升级一次；便携版没有更新能力。不绕过系统安全策略；无法启动辅助进程时保持当前程序运行并提供手动下载。
