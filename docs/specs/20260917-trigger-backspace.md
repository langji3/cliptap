# 触发词退格纠错

用户反馈 `v0.1.0` 在触发词输入错误、退格删除几个字符后继续输入无法匹配。用户要求修复；沿用已验证版本，工作分支 `codex/trigger-backspace-fix` 基于 `8c3f10a`。

- 同一输入框、半角英文模式下，普通 Backspace 按真实删除次数回退触发词状态，允许连续及长按退格。
- 正确前缀只保存已配置触发词的部分，错误 ASCII 字符只累计数量，不保存字符内容；退格删完错误部分后恢复前缀匹配。
- 新 `!` 重新开始匹配；空格、非 ASCII、超过 64 字符的纠错范围、5 秒无输入、焦点/布局变化、导航和组合键仍重置。Ctrl/Shift+Backspace 和 Delete 不尝试推断删除内容。
- 不读取目标输入框，不改变用户库，不安装测试。完成代码、规则回归及专用虚构输入窗口验证后提供 0.1.1 安装包，由用户自行安装。已公开的 0.1.0 不覆盖。
