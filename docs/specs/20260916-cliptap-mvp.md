# ClipTap 第一版需求

## 背景与目标
实现轻量、简约、纯本地的 Windows 剪贴板与快捷片段工具。用户已在本次对话确认双 Tab 交互，并要求「计划一下，开始做了」。英文产品名为 ClipTap，目录为 cliptap。

## 仓库与分支
从空目录初始化，当前实现分支为 `ai/20260916-cliptap-mvp`，没有已有开发者分支或源提交。用户额外要求创建公开 GitHub 仓库，默认使用当前登录账号，以 MIT 许可证发布源码。首版完成后推送实现分支；不自动合并其他已有分支。

## 范围
- Windows 托盘常驻，单实例；默认全局快捷键 Ctrl+Alt+V；可选开机启动。
- 每次唤起默认剪贴板 Tab，选中最新文本记录；左右键切换 Tab，上下键选择。
- 回车或鼠标单击选择项：恢复原前台窗口并发送粘贴；Esc、失焦收起。
- 无有效目标或无法恢复焦点时只复制，给予提示；不向未经核验的其他前台窗口发送输入。
- 仅文本历史、去重、条数上限、暂停记录和清空历史。
- 快捷片段的创建、编辑、删除、置顶。列表显示标题；敏感内容遮蔽，不自动显示明文。
- 本地数据用 Windows DPAPI 绑定当前用户加密；敏感片段不进入自身历史；尽量通过 Windows 剪贴板格式标记排除系统历史和云同步。
- 敏感插入需要明确确认。系统剪贴板仍可能被其他程序读取，文档说明此边界。
- 提供构建、测试、运行、打包说明、中文 README、许可证及公开仓库。

## 非目标
本次不实现 `!hzpass` 触发词展开、图片/文件历史、云同步、账号、插件或复杂分类。

## 技术与影响区域
C# / .NET 10 / WPF，Windows API 负责快捷键、事件驱动剪贴板监听、窗口焦点和粘贴；Windows Forms 仅用于托盘。核心规则与桌面集成分开。影响 src/、tests/、scripts/、docs/、项目与构建配置、README、LICENSE、GitHub CI。

## 实现计划
1. 建立项目、纯逻辑模型与持久化接口。
2. 建立双 Tab 浮窗、编辑器、设置、托盘和 Windows 集成。
3. 验证历史去重与上限、片段排序、加密保存、故障与边界；构建可运行产物。
4. 独立只读审查并修复重要问题，发布代码与交付说明。

## 验证与验收
- Release 构建通过；逻辑测试覆盖真实边界而非仅检查实现细节。
- Windows 集成验证覆盖加密往返、监听、快捷键注册、输入结构布局；条件允许时验证真实窗口粘贴。
- 启动无异常、托盘可退出、唤起后总是历史、方向键工作、空状态可理解。
- 尝试实际 UI 验证；不可执行的跨应用场景明确记录，不把构建通过当作全部交互已验证。

## 风险及范围管理
Windows 限制向管理员窗口注入输入，且不同软件的焦点/粘贴处理存在差异。使用标准 Ctrl+V 并核验原窗口；失败提示手动粘贴。不得把密码加密存储描述为运行中完全不可读。保存失败必须可见，不悄悄覆盖不可解密的已有数据。新增范围先记录，涉及未授权业务变化时再询问。
