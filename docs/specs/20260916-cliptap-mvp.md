# ClipTap 第一版需求

## 背景与目标
实现轻量、简约、纯本地的 Windows 剪贴板与快捷片段工具。用户已在本次对话确认双 Tab 交互，并要求「计划一下，开始做了」。英文产品名为 ClipTap，目录为 cliptap。

## 仓库与分支
从空目录初始化，当前实现分支为 `ai/20260916-cliptap-mvp`，没有已有开发者分支或源提交。用户额外要求创建公开 GitHub 仓库，默认使用当前登录账号，以 MIT 许可证发布源码。首版完成后推送实现分支；不自动合并其他已有分支。

## 范围
- Windows 托盘常驻，单实例；默认全局快捷键 Alt+空格；可选开机启动。
- 每次唤起默认剪贴板 Tab，选中最新文本记录；左右键切换 Tab，上下键选择。
- 回车或鼠标单击选择项：恢复原前台窗口并发送粘贴；Esc、失焦收起。
- 顶部栏（设置按钮除外）支持拖动，标题旁不显示短描述，保持简洁。
- 列表、设置、新建/编辑片段在同一浮窗内切换；左上返回、Esc 返回列表，表单中方向键与 Enter 保持正常编辑行为。
- 删除、清空、敏感粘贴使用页内确认，不打开新的模态窗口；保存失败停留当前页面并显示必要错误。
- 移除宣传语、列表分区说明、冗长空状态和常驻键盘说明；列表底部只保留「Alt+空格唤醒」，异常状态按需显示。设置入口使用矢量调节图标。
- 编辑/设置失焦收起后保留当前页面与未提交内容，重新唤起可继续；返回后再次唤起列表时仍默认剪贴板。
- 无有效目标或无法恢复焦点时只复制，给予提示；不向未经核验的其他前台窗口发送输入。
- 仅文本历史、去重、条数上限、暂停记录和清空历史。
- 快捷片段的创建、编辑、删除、置顶。列表显示标题；敏感内容遮蔽，不自动显示明文。
- 本地数据用 Windows DPAPI 绑定当前用户加密；敏感片段不进入自身历史；尽量通过 Windows 剪贴板格式标记排除系统历史和云同步。
- 敏感插入需要明确确认。系统剪贴板仍可能被其他程序读取，文档说明此边界。
- 提供构建、测试、运行、打包说明、中文 README、许可证及公开仓库。
- 按用户追加要求支持浅色、深色主题；默认浅色，同时提供深色和跟随系统，设置中切换并持久保存，所有自有窗口统一配色。
- 按用户追加要求支持蓝、绿、紫主题色，与明暗模式独立组合；重做原生矢量剪贴板标识及多尺寸应用/托盘图标。

## 非目标
本次不实现 `!hzpass` 触发词展开、文件历史、云同步、账号、插件或复杂分类。

## 追加：Windows 原生历史数据源
用户要求接入 Windows 原生记录。剪贴板列表改为读取 Win+V 的文本历史，以系统当前快照为准；唤起和系统历史变化时刷新，不再自行长期记录新复制内容。系统关闭历史、拒绝访问或暂时不可用时显示简短状态；提供系统剪贴板设置入口，不自行启用系统功能。

历史快照仅在内存中，不导入本地加密库；旧版已有记录保留在原库但不再显示。快捷片段继续本地加密保存；匹配敏感片段的系统文本不在本工具中显示，但不会擅自删除系统记录。首版仅展示文本，不展示图片/文件；不自行截断、去重或限制系统历史条数。用户进一步确认「和系统的一致就可以了，没必要自己写逻辑」，移除主动采集和自身历史管理方法。

取消 ClipTap 的历史条数和暂停记录选项，改由 Windows 管理。设置中的清空须明确确认「清空 Windows 历史」，调用系统接口，不以清空本地缓存冒充系统清空。异步刷新失败不崩溃，旧请求不得覆盖较新结果。验证使用隔离假数据，不在日志、截图或 Git 中暴露真实系统剪贴板文本，也不在测试中清空用户历史。

## 技术与影响区域
追加图片支持：显示 Win+V 的 Bitmap 项及有界缩略图，沿用上下选择、回车/单击粘贴。缩略图仅内存展示，失败时显示图片占位，不丢弃条目；粘贴通过 Windows 恢复原始历史项，不能把缩略图作为实际粘贴内容。原记录已删除/不可恢复时停留列表提示，不发送粘贴。图片不写入本地片段库、不另建历史。以合成图片验证缩略图尺寸和图文混排；真实跨应用粘贴未验证时明确说明。

C# / .NET 10 / WPF，Windows API 负责快捷键、事件驱动剪贴板监听、窗口焦点和粘贴；Windows Forms 仅用于托盘。核心规则与桌面集成分开。影响 src/、tests/、scripts/、docs/、项目与构建配置、README、LICENSE、GitHub CI。

## 实现计划
1. 建立项目、纯逻辑模型与持久化接口。
2. 建立双 Tab 浮窗、编辑器、设置、托盘和 Windows 集成。
3. 验证历史去重与上限、片段排序、加密保存、故障与边界；构建可运行产物。
4. 独立只读审查并修复重要问题，发布代码与交付说明。

## 验证与验收
- Release 构建通过；逻辑测试覆盖真实边界而非仅检查实现细节。
- Windows 集成验证覆盖加密往返、监听、快捷键注册、输入结构布局；条件允许时验证真实窗口粘贴。
- 启动无异常、托盘可退出、唤起后总是历史、方向键工作、空状态可理解。
- 尝试实际 UI 验证；不可执行的跨应用场景明确记录，不把构建通过当作全部交互已验证。

## 风险及范围管理
Windows 限制向管理员窗口注入输入，且不同软件的焦点/粘贴处理存在差异。使用标准 Ctrl+V 并核验原窗口；失败提示手动粘贴。不得把密码加密存储描述为运行中完全不可读。保存失败必须可见，不悄悄覆盖不可解密的已有数据。新增范围先记录，涉及未授权业务变化时再询问。
