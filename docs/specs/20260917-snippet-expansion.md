# 快捷片段触发词替换

用户已要求计划并开始实现原定的 `!hzpass` 快捷替换功能。沿用当前 `ai/20260916-cliptap-mvp` 工作分支，保留面板与 Tab 交互。

## 行为

- 片段新增可选触发词，示例 `!hzpass`。留空关闭该片段的自动替换，旧数据兼容。
- 规则为 `!` 加 2–31 个小写英文字母、数字或下划线，末尾为字母或数字（替换时不能按住 Shift）；精确匹配，禁止重复及互为前缀。
- 英文输入状态连续输入完整触发词，直接替换为片段内容，无需打开面板或按空格。
- 第一版触发词仅用于单行、无控制字符、最多 2000 个 UTF-16 字符的内容；普通面板粘贴仍支持原有 20000 字符及多行。
- 明确配置触发词即启用该项自动输入，敏感值同样自动输入；不写剪贴板，不记键盘日志。仍使用 DPAPI 保存片段与触发词。
- 托盘提供暂停/恢复自动替换。监听失败提示，面板功能继续可用。

## 保护与边界

- 仅保留与已配置触发词匹配的短前缀，超时、焦点/窗口变化、鼠标操作、导航/删除键或组合键重置。
- 不在 ClipTap 自身、中文组词状态及系统桌面匹配。不展开注入输入、不递归展开值。
- 只删除此前已输入的触发词字符，最后字符由钩子拦截。删除和 Unicode 输入作为一批 SendInput 发送；零发送时不拦截原键，部分失败不自动重试。
- Windows 权限与目标控件限制仍存在。自动完成、网页脚本或控件自身拦截按键可能改变结果，不能保证所有应用；管理员窗口不提升权限。

## 验证

规则测试覆盖格式、冲突、旧数据、敏感内容、前缀重置与超时；界面测试覆盖新增/修改/清空触发词和错误提示；原生集成使用专用输入窗口与虚构数据，避免读取或更改用户输入。
