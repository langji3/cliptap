# 统一复制粘贴流程

用户最终选择：文本、图片、快捷片段统一先复制再粘贴，历史列表不因使用而跳动；敏感片段无需二次确认，不再 30 秒后或退出时清除当前剪贴板；去掉确认按钮的虚线焦点框。

Windows 历史文本和图片均通过原历史项的 SetHistoryItemAsContent 恢复，避免重新写文本造成重复记录和时间更新。每次恢复重新检查系统历史项，已删除的项不从缓存复活。列表按原复制时间排列、按 ID 记住选择，新复制项目仍在顶部。快捷片段写入当前剪贴板，敏感项继续带历史与云同步排除标记。

不维护独立历史内容库。若原目标不可用，内容仍留在当前剪贴板，提示用户 Ctrl+V 手动粘贴。删除与清空操作仍需确认。
