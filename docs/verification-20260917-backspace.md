# 触发词退格纠错验证

- 原因：服务把 Backspace 视为重置键；匹配器在第一个错字出现时也直接清空前缀。因此退格无法恢复匹配。
- 修复：记录已匹配前缀和错字数量；普通 Backspace 回退，错误后续字符只累计数量，不保存字符内容；支持退格自动重复。Shift/Ctrl 等组合删除、导航、焦点变化、超时继续重置。
- Release 构建无警告/错误，默认 32 项测试通过；专用跨进程纠错测试总计 33 项通过，覆盖正确前缀重输、多错字、长按退格、导航取消匹配，前文保留且剪贴板序列号不变。
- 独立只读审查未发现明确的错删、隐私或状态重置问题。仍受目标应用改写文本/拦截按键的原有限制。
- 用户确认将此修复直接发布为补丁版本 0.1.1，由用户自行安装；未执行安装测试，未更新当前正式安装目录，不覆盖已发布的 0.1.0。
