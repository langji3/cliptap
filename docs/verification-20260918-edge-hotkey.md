# Edge 前台快捷键增强

现象：桌面可用 Alt+空格，Edge 前台无面板，右上角菜单按钮出现键盘焦点框。截图不足以区分按键拦截与面板激活失败。

实现：独立消息线程上的低级键盘钩子优先捕获纯 Alt+空格，吞掉空格的按下、重复与释放。注入不产生字符的未分配虚拟键以取消 Alt 单键菜单行为，完整松键后通过消息唤出面板。窗口显示后明确请求前台激活。保留 RegisterHotKey 作为后备；不声明系统范围的绝对最高优先级。

验证：Release 构建、33 项测试通过。新增覆盖两种松键顺序、长按去重、普通空格、其他修饰键、Alt+Tab 放行、中途其他键取消，以及原生消息窗口的两种事件路由。未安装或替换用户版本；尚未实测 Edge 前台的真实按键链路，因此兼容性效果待实际使用验证。
