增强 Alt+空格的捕获和窗口激活，针对 Edge 前台无法唤出、菜单按钮出现焦点框的问题进行修复。

- 使用独立线程的键盘钩子优先捕获 Alt+空格，拦截空格事件并抑制 Alt 菜单焦点。
- 松开两个键后唤出 ClipTap；长按不会反复开关面板。
- 保留普通空格、单独 Alt、Alt+Tab 和带 Ctrl/Shift 的组合键行为，以及原有全局快捷键后备通道。

Release 构建和 33 项自动测试通过；Edge 的真实按键场景尚未完成实机验证，不保证系统范围的绝对最高快捷键优先级。

v0.1.2 及以上安装版可在设置中点击“检查更新”→“立即更新”。更新沿用当前目录，保留片段和设置。更早版本请退出托盘程序后手动运行安装包覆盖升级。

安装版：`ClipTap-win-x64-setup.exe`；便携版：`ClipTap-win-x64-portable.zip`。两个包均自带运行时，校验值见 `SHA256SUMS.txt`。
