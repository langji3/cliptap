为浮窗增加细磨砂材质，保持内容清晰、界面轻巧。

- 外层浮窗新增细颗粒纹理、柔光与边缘高光，适配浅色、深色及三种主题色。
- 卡片和输入框保持实色；静态材质不采样或透出桌面内容。
- README 更新材质介绍、浅色和深色预览图及升级说明。

**升级：** v0.1.2 安装版可在设置中点击“检查更新”→“立即更新”，沿用当前安装目录，保留片段和设置。v0.1.0 / v0.1.1 请退出托盘程序后，手动运行新版安装包覆盖升级。

安装版下载 `ClipTap-win-x64-setup.exe`；便携版下载并解压 `ClipTap-win-x64-portable.zip`。两个包均自带运行时，校验值见 `SHA256SUMS.txt`。
