ClipTap 的首个正式发布版本：一个轻量的 Windows 剪贴板历史与快捷片段工具，让常用内容随取随贴。

## 主要功能

- **快捷唤起**：按 `Alt + 空格` 打开浮窗，使用键盘或鼠标选择内容，用完即收起，平时驻留托盘。
- **系统剪贴板历史**：读取 Windows 已有的文本和图片历史，支持预览、粘贴和删除。
- **快捷片段**：保存常用文本，支持编辑、置顶和自定义触发词。在英文输入状态下输入完整触发词，即可自动替换为片段内容。
- **敏感片段保护**：编辑时默认遮蔽内容，从面板粘贴前确认；片段使用 Windows DPAPI 在本地加密保存。触发词替换通过 Unicode 输入完成，不经过剪贴板。
- **外观设置**：支持浅色、深色、跟随系统，以及蓝、绿、紫三种主题色；首次使用默认浅蓝色图标。
- **安装版检查更新**：在设置页主动检查 GitHub 新版本，发现更新后前往下载。

## 下载与安装

适用于 Windows 10 / Windows 11，x64。

| 文件 | 用途 |
| --- | --- |
| `ClipTap-win-x64-setup.exe` | 推荐。双击后按中文向导安装，可选择安装位置；内置 .NET 运行时。 |
| `ClipTap-win-x64-portable.zip` | 免安装。完整解压后运行 `ClipTap.exe`；内置运行时，不提供检查更新功能。 |
| `SHA256SUMS.txt` | 上述两个文件的 SHA-256 校验值。 |

安装版不创建桌面或开始菜单快捷方式。完成页默认勾选运行，启动后驻留托盘，不弹出主窗口。安装或升级前，请先从托盘退出正在运行的 ClipTap。

首次使用剪贴板历史，请在 Windows 设置中启用“剪贴板历史记录”。按 `Alt + 空格` 打开 ClipTap，切换到快捷片段后可新增常用内容。

## 数据与使用说明

- 快捷片段和设置保存在 `%LOCALAPPDATA%\ClipTap\library.dat`，与安装目录分离；卸载保留这份数据。加密绑定当前 Windows 用户，跨电脑或重装系统后通常无法直接解密。
- 不上传剪贴板或片段内容。仅安装版主动检查更新时访问 GitHub 版本接口。
- 自动替换要求半角英文输入，中文组词、焦点切换、组合键等会取消匹配；部分输入法、管理员窗口及自定义输入控件的兼容性仍需完善。
- 本版本提供更新检查和下载入口，不会静默安装更新。安装程序暂未进行代码签名。
